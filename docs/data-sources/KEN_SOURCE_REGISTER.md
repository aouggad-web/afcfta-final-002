## Règles de preuve

- Les mesures sont reliées à une version HTML consolidée ou à un original officiel archivé.
- `DIRECT_HS` signifie que le code apparaît dans le texte; `LEGAL_DESCRIPTION` ne propose aucun code; `MAPPED_HS` est une proposition distincte et impose une revue humaine.
- Une date manquante ou calculée est signalée par `verification_status`; elle ne doit pas alimenter un calcul juridique silencieusement.
- L'ancienne édition KRA 2009 de l'EACCMA n'est pas utilisée comme consolidation actuelle.
