# Togo — Taxes, droits et accises collectés par la Douane (OTR/CDDI) + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : otr.tg (Office Togolais des Recettes), togotrade.gouv.tg, commerce.gouv.tg, segucetogo.tg, intercom.tg.

## 1. Taux officiels des droits, taxes et redevances (tableau OTR)

| Code | Désignation | Taux / Base |
|---|---|---|
| **DD** | Droit de Douane (TEC CEDEAO) | 5 / 10 / 20 / 35 % — sur **valeur CAF** (cat. 0 = 0 %) |
| **RS** | Redevance Statistique | 1 % CAF |
| **PCS** | Prélèvement Communautaire de Solidarité (UEMOA) | 0,8 % CAF |
| **PC** | Prélèvement Communautaire (CEDEAO) | 0,5 % CAF |
| **PUA** | Prélèvement Union Africaine | 0,2 % CAF |
| **PNS** | **Prélèvement National de Solidarité** | 0,5 % CAF (spécificité togolaise) |
| **TVA** | Taxe sur la Valeur Ajoutée | 18 % — base : valeur en douane **+ tous droits et taxes liquidés** (hors TVA) |
| **BIC** | Acompte Bénéfices Industriels et Commerciaux | 1 % (avec carte d'immatriculation fiscale valide ; 5 % NIF seul, 20 % sinon en gros intérieur) |
| **RIV** | Redevance Inspection et Vérification | 0,75 % |
| **RI** | Redevance Informatique | **5 000 FCFA / déclaration (DDU)** |
| **TPI** | Taxe de Protection des Infrastructures | **2 000 FCFA / tonne indivisible sur le poids brut** |
| **TP** | Taxe de Péage | 200 FCFA / tonne |
| **DPS** | Droit de Passage au Scanner | **50 000 F/conteneur · 10 000 F/voiture · 20 000 F/camion** |
| **TD** | Timbre Douanier | 4 % |
| **ADA** | Autres Droits d'Accises | Selon loi de finances (CGI art. 243 — tabacs, boissons ; carburants : 57,70 F/l super, 48,06 F/l gasoil) |
| **TSR** | Taxe Spéciale de Réexportation | 1 % |
| — | Prélèvement spécifique export agro-élevage-pêche | 1 % des bénéfices ; prélèvement spécifique noix de cajou |
| — | Retenue défaut d'attestation de régularité fiscale | **15 %** de la valeur en douane au cordon (Livre des procédures fiscales, art. 10) |

Exo CEDEAO/UEMOA (certificat d'origine valide) : DD, RS et prélèvements communautaires annulés — **TVA reste due**.

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires en Douane Agréés (CDA)** | Seuls habilités à lever la déclaration dans SYDONIA World (loi 2018-007) ; liste annuelle OTR | Honoraires libres ; seuil CDA obligatoire si valeur > 200 000 FCFA (aéroport) |
| **SEGUCE Togo** (GUCE, décret 2013-083) | Manifeste, **DFU (Document de Frais Unique)** regroupant douane + PAL + consignataire + manutentionnaire + Antaser + SEGUCE ; payé en banque partenaire (UTB, IB, Ecobank, Orabank) | Facture SEGUCE sur le DFU |
| **Antaser Afrique** | **BESC** (Bordereau Électronique de Suivi des Cargaisons) | **25 000 F/tranche de 5 conteneurs** (Afrique/Europe) · **70 000 F/5 conteneurs** (Asie/autres) ; inclus dans le DFU |
| **PAL** (Port Autonome de Lomé) | Bon à délivrer, manutention, enlèvement | Frais de demande d'enlèvement **5 000 FCFA** ; acconage selon terminal (LCT, Togo Terminal…) |
| **CCIT** (Chambre de Commerce et d'Industrie) | Caution nationale TRIE, certificats d'origine | **Cotisation fonds de garantie : 0,25 % de la valeur CAF** — en transition vers la garantie unique CEDEAO (Acte A/SA.2/12/21 du 12/12/2021) |
| **OTR / DODLP** | Transit : déclaration IM8 → **T1 électronique + balise de suivi** (RFID déployé depuis 03/2023 sur corridor Cinkassé) | Redevances de transit ; contrôle via SIGMAT (Togo-Burkina-Niger, déployé 2018) |
| **UMCC / CNCT / CBC / CNUT / EMATO** | Structures notifiées au manifeste (contrôle conteneurs, chargeurs) | Frais propres sur le DFU selon cas |
| **Attestation régularité fiscale** | Obligatoire à l'enlèvement | À défaut : retenue 15 % |
