# Burkina Faso — Taxes, droits et accises collectés par la Douane + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : douanes.bf, dgi.bf, burkinatradeportal.bf, finances.gov.bf, OMC.

## 1. Fiscalité de porte à l'importation (TEC CEDEAO + taxation nationale)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **Droit de Douane (DD)** — TEC CEDEAO | Valeur en douane (CAF) | 0 / 5 / 10 / 20 / 35 % | Moyenne NPF 12 % (OMC 2024) ; annulé intra-communautaire (TPC UEMOA / SLE CEDEAO avec certificat d'origine) |
| **Redevance Statistique (RS)** | Valeur CAF | 1 % | |
| **Prélèvement Communautaire CEDEAO (PCC)** | Valeur CAF | 0,5 % | Pays tiers |
| **Prélèvement Communautaire de Solidarité UEMOA (PCS)** | Valeur CAF | 0,8 % | |
| **Prélèvement de l'Union Africaine (PUA)** | Valeur CAF | 0,2 % | |
| **TVA à l'importation** | Valeur en douane + DD + taxes perçues par la douane (art. 310 CGI) | **18 %** (taux réduit 10 % hébergement/restauration) | Recouvrée par la Régie des Douanes ; exo art. 307–308 CGI (pharma, médical, denrées, livres) ; suspension différée pour régimes suspensifs (art. 307.8) |
| **ISCP** — Impôt Spécial sur Certains Produits (droits d'accises) | CAF + DD + RS | Tabacs, boissons alcoolisées et non alcoolisées, armes, sachets plastiques… (barèmes CGI/décrets) | Équivalent droits d'accises |
| **TCI** — Taxe Conjoncturelle à l'Importation | Prix de déclenchement UEMOA | sucre/huiles (péréquation) | Dispositif communautaire |
| **Taxes spécifiques** (chapitre 27 pétrole, tabacs, boissons) | Unité physique ou CAF | tarif en ligne SYDONIA | Douane BF : tarif en ligne + simulateur sur douanes.bf |

À l'exportation : coton, sésame, or… — droits et taxes sectoriels selon textes (or : prélèvements code minier).

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires en douane agréés (CAD)** | Obligatoires pour opérations commerciales (art. 61–62 Code des douanes) ; se procure les imprimés douaniers auprès de la CCI-BF | Honoraires libres ; enregistrés à la CCI-BF |
| **CCI-BF** (Chambre de Commerce et d'Industrie) | Imprimés douaniers, certificats d'origine, agréments TPC/SLE | Frais selon barème CCI |
| **SYLVIE / SOGESY** (Système de Liaison Virtuelle Import-Export) | Titres import/export, certificats, attestations ; V2 lancée 17/02/2025 (signature numérique, e-paiement) ; interconnectée à SYDONIA depuis 21/10/2021 | Abonnement/prestations selon barème SOGESY ; guichet unique en construction |
| **SYDONIA World** (portail DGD) | Tarif en ligne, simulateur, acte d'inspection, suivi documents | douanes.bf/sydoniabf |
| **Cautions / soumissions cautionnées** | Transit, entrepôts (réel 5 ans, fictif 18 mois, spécial 3 ans, industriel 1 an), admission temporaire, crédit d'enlèvement (art. 79, 82–83) | Obligation bancaire ; intérêt de crédit + remise spéciale par arrêté MEF |
| **BCEAO / banques agréées** | Domiciliation des opérations, apurement | Frais bancaires |
| **Agences réglementaires connectées SYLVIE** (LNSP, ARP, guichet unique, DAMF…) | Certificats sanitaires/pharma pour dédouanement | Barèmes propres à chaque agence |

## 4. Mise à jour 2025–2026

- **Loi de finances 2026** : loi n°021-2025/ALT du 27/12/2025 (en vigueur 01/01/2026, budget 3 431,5 Mds FCFA) — mesures clés (présentation DGI) :
  - **Taxe Spécifique sur l'Importation des Armes et Munitions** (art. 24 LFI, art. 382-1 nouveau CGI) — recouvrement par les **douanes aux frontières**, compte d'affectation spéciale
  - **Retenue à la source TVA de 30 %** (RASTVA, art. 334 CGI) élargie aux entreprises de la DGE et aux organismes payeurs de marchés publics
  - Exo TVA élargie : bétail (bovins non reproducteurs, caprins, ovins), karité, cajou, œufs à couver, bonbonnes fibre de verre
  - Reconduction exonération TVA/DD sur systèmes électroniques certifiés de facturation (SeCeF, art. 40) ; régime spécial d'exonération projets stratégiques ; exo patente pétroliers/entités publiques
- **Nouveau Code des douanes** : adopté par l'ALT le **24/03/2025** (remplace le texte de 1962) — suivi électronique des camions de transit, contrôle non intrusif, paiement électronique des droits, LBC/FT, alignement AFE OMC et CKR OMD (texte intégral non encore publié en ligne — remplacera la loi 03/92 jointe)
- **Prévisions 2026** : droits et taxes à l'importation 386,6 Mds FCFA ; à l'exportation 458,07 Mds FCFA
