# Cabo Verde — collecte (partielle, IVA seule)

Consultation : 2026-07-25.

Collecte délibérément incomplète : IVA seule vérifiée sur le Regulamento do IVA (Lei nº 21/VI/2003 de 14 de Julho) ; l'ICE (Imposto sobre Consumos Especiais, équivalent accises) n'a pas pu être archivé dans ce cycle.

## Ce qui a été vérifié sur texte primaire

- **IVA taux standard 15%** — Artigo 17º, Regulamento do IVA (Lei nº 21/VI/2003).
- **Exportações isentas com direito a dedução** (taux zéro) — Artigo 13º-1(a) et (b).

## Ce qui n'a PAS été collecté

- **Imposto sobre Consumos Especiais (ICE)** — Lei nº 22/VI/2003, promulguée le même jour que la loi IVA. Le seul lien officiel identifié (`igae.cv`, Instituto de Gestão da Administração Estatal) est **bloqué par la politique réseau de cet environnement de collecte** (« Host not in allowlist: igae.cv »). Le portail `mf.gov.cv` (Ministère des Finances, source de la loi IVA) ne semble pas héberger de miroir de ce document. À rattraper dans un cycle avec accès réseau élargi.
- **Taux réduits IVA** (le cas échéant) : non recherchés dans ce cycle.
- **Tarif Extérieur Commun (TEC) CEDEAO** : Cabo Verde applique un régime tarifaire insulaire propre, non archivé dans ce cycle.

## État de l'enregistrement

Juridiction CPV : **non** enregistrée dans `SUPPORTED_JURISDICTIONS` — IVA seule vérifiée, accises (ICE) manquantes pour une couche complète. ZLECAf : **pas** d'offre nationale encore enregistrée dans `NATIONAL_OFFER_REGISTRY`.
