# Guinée — Taxes, droits et accises collectés par la Douane (DGD) + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : dgd.gov.gn (DGD Guinée), guceg.gov.gn (GUCEG), mbudget.gov.gn, guineelex.com.

⚠️ Guinée = CEDEAO mais **hors UEMOA** (franc guinéen GNF) : pas de PCS ; fiscalité propre avec **DFI** (Droit Fiscal à l'Importation), **RTL**, **DUE**, **CA**.

## 1. Fiscalité de porte à l'importation (TEC CEDEAO + taxation nationale guinéenne)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **DD** — Droit de Douane (TEC CEDEAO) | Valeur en douane | 0 / 5 / 10 / 20 / 35 % | 5 catégories CEDEAO |
| **DFI** — Droit Fiscal à l'Importation | Valeur en douane | **0 à 30 %** (tarif guinéen) | Distinct du DD ; seuil « marchandises fortement taxées » ≥ 20 % |
| **TVA à l'importation** | VD + tous droits et taxes liquidés (hors TVA) | **18 %** (0 % exportations) | Remboursement crédit taxe après 3 mois (45 j code minier) |
| **RTL** — Redevance de Traitement des Liquidations | Valeur | **2 %** | Frais administratifs DGD |
| **DUE** — Droit d'Entrée Unique | Valeur | 6 % (matières premières) · 6,5 % exploitation minière (extraction) · 5 % (transformation sur place) · 5,6 % produits pétroliers sociétés minières | Régimes conventionnels (code des investissements, code minier) |
| **CA** — Contribution Additionnelle / **TE** (taxe d'équipement) | Valeur | selon régime (codes minier/investissements) | Combinaisons par régime : voir table des régimes |
| **PC** — Prélèvement Communautaire CEDEAO | Valeur | 0,5 % | |
| **Accises spécifiques** (tabacs, alcools, hydrocarbures, véhicules, télécoms) | ad valorem ou spécifique | barèmes LFI | LFI annuelle (loi de finances initiale) |
| **TAI / TCP** | Valeur | selon produit | Ajustement/protection (CEDEAO) |

**Régimes dérogatoires documentés** (table des régimes, arrêté A/2020/517) : ~150 combinaisons (minières : phases recherche/construction/exploitation ; dons ; ONG ; diplomates ; marchés publics ; conventions bilatérales Maroc…).

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires en Douane Agréés (CDA)** | Seuls habilités au dédouanement ; **solidairement responsables** du paiement des droits avec leur client (art. 450 CD) | Honoraires libres ; agrément DGD |
| **GUCEG** (Guichet Unique du Commerce Extérieur de Guinée, guceg.gov.gn) | Modules E-Voyage (escales), E-Manifeste, E-Booking, E-Mouvement, E-Release ; interfacé SYDONIA World en temps réel ; PCS Port Community System | Prestations GUCEG selon barème |
| **Port Autonome de Conakry** | Escales, acconage, magasinage | Tarifs officiels PAC ; 90 % du commerce extérieur |
| **Cautions** | Transit, entrepôt, admission temporaire (soumissions cautionnées) | Banques locales |
| **BIVAC / sociétés de vérification** | Pré-vérification des importations (selon programme en vigueur) | % FOB selon contrat État |
