# Niger — Taxes, droits et accises collectés par la Douane + frais du transit (corridors Cotonou/Lomé → Niamey)

Dossier de livrables (collecte du 10/10/2026). Sources : douanes.gov.ne (DGD Niger), ksim-ibro.e-monsite.com, bwcimplementation.org, mde.ne (CGI), douanes.gouv.bj, CNUCED.

⚠️ Contexte 2025–2026 : Niger sort de la CEDEAO le **29/01/2025** (avec Mali et Burkina) mais reste **membre UEMOA**. La CEDEAO demande de continuer à appliquer le SLE ; le code des douanes (loi 2018-19) vise « la Communauté » (CEDEAO ou UEMOA). Transit régi par TRIE + **SIGMAT** (corridor Cotonou–Niamey interconnecté depuis 2019-2020) et code des douanes UEMOA.

## 2. Frais du transit (corridors Cotonou–Niamey et Lomé–Niamey)

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires Agréés en Douane (CAD)** | Déclaration, transit IM8/T1 | Honoraires libres |
| **Caution transit (acquit-à-caution / soumission cautionnée)** | Garantie des droits théoriques jusqu'à destination | Banques ; remise spéciale + intérêt de crédit (art. 58 bis) |
| **Crédit d'enlèvement** | Enlèvement avant paiement | Remise **1‰ puis 2‰** du montant des droits (art. 62 / 62 bis) + pénalité de retard 15 jours |
| **Guichet Unique GUCE Bénin (corridor Cotonou)** | **BFU** (Bordereau de Frais Unique) payable une fois | Regroupe toutes les factures (douane Bénin + PAC + manutention + structures) |
| **Bénin Control (BSE + balise)** | Transit vers Niger : **Bordereau de Suivi Électronique + balise GPS + laissez-passer**, suivi corridor, ASE à la sortie | Frais selon barème Bénin Control ; pénalités si non-respect délai de route |
| **Douane Niger (Gaya, Torodi…) / péages** | Formalités entrée | Variable selon enquête CNUCED 2024 : péages 1 000–10 000 FCFA ; Gaya ≈ 3 000 FCFA douane + 500 F syndicat |
| **Sigle SIGMAT** | Confirmation électronique d'arrivée T1 | Dédouanement transit à la frontière réduit à **~1 heure** (corridor Cotonou–Niamey) |
| **Parcs de stationnement** (Bodjékali…) | Stationnement | Temps moyen ≈ 19 h (CNUCED 2024) |
