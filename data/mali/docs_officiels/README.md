# Mali — Taxes, droits et accises collectés par la Douane + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : douanes.gouv.ml, sgg-mali.ml, mali.tradeportal.org, dirpharma.ml, greatmali.net.

## 1. Fiscalité de porte à l'importation (structure officielle DGD Mali)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **Droit de Douane (DD)** — TEC CEDEAO | Valeur CAF | 0 / 5 / 10 / 20 / 35 % | Annulé dans les échanges intra-communautaires (avec certificat d'origine UEMOA/CEDEAO) |
| **Redevance Statistique (RS)** | Valeur CAF | 1 % | |
| **Prélèvement Communautaire CEDEAO (PC/PCC)** | Valeur CAF | 0,5 % | |
| **Prélèvement Communautaire de Solidarité UEMOA (PCS)** | Valeur CAF | 0,8 % | |
| **TVA à l'importation** | CAF + droits et taxes | 18 % (réduit 5 % matériels agricoles et informatiques) | CGI Mali |
| **ISCP** — Impôt Spécial sur Certains Produits (droit d'accise) | CAF + DD + RS | Cola 10–30 % · boissons non alcoolisées 0–20 % · boissons alcoolisées 15–50 % · tabac 15–45 % · armes/munitions 15–40 % · sachets plastiques 5–10 % · marbre 5–10 % · or 3–15 % · véhicules tourisme >13 CV 5–10 % | Plafonds fixés par le CGI, taux par décret en Conseil des Ministres |
| **Taxes d'Ajustement à l'Importation (TAI)** | Valeur CAF | selon ligne tarifaire | Taxes conjoncturelles de protection |
| **Taxe Complémentaire de Protection (TCP)** | Valeur CAF | selon ligne | |
| **TIPP** — Taxe Intérieure sur les Produits Pétroliers | Produits pétroliers | tarif officiel | Perçue à la porte |
| **TEOAPM** — Taxe des exportateurs d'or et produits miniers (hors code minier) | Valeur exportations | 2 % | |
| **Taxe forfaitaire** (petits envois/bagages) | Forfait | taux fixé par la loi | Art. 11 Code des douanes |

À l'exportation : pas de droits de porte (prise en charge statistique), hors taxes sectorielles (TEOAPM, taxes minières/agricoles).

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires agréés en douane (CAD)** | Obligatoires pour la déclaration en détail (art. 86-88 Code des douanes) ; acquittent pour le compte du commettant droits/taxes/amendes | Honoraires libres ; responsables des formalités du commerce extérieur |
| **Intention d'Importation (II) / d'Exportation (IE)** — DGCC/DNCC | Levée obligatoire ≥ 250 000 FCFA FOB | **1 500 FCFA** par document |
| **PVI** (Programme de Vérification des Importations, BIVAC) | Vérification avant embarquement ≥ 3 000 000 FCFA FOB | **0,75 % de la valeur FOB** (chèque certifié) + Attestation de Vérification (AV) |
| **Domiciliation bancaire** | Obligatoire pour tout transfert | Frais bancaires selon banque |
| **Redevance informatique (SYDONIA World)** | Déclarations IM4/IM8, génération T1 | Arrêté n°01-3299/MEF-SG (redevance informatique) |
| **Fonds de garantie du transit (TRIE)** | Contribution sur déclarations de transit | **0,25 % du montant de la marchandise** + redevance informatique |
| **Fonds de garantie / caution** | Acquits-à-caution, T1 transit, admission temporaire | Soumission cautionnée bancaire obligatoire |
| **Port Sec de Bamako (PSM)** | Prestations portuaires/logistiques | Facture PSM (tarifs officiels) |
| **Frais de passage / travaux supplémentaires / escorte** | Douane (hors heures légales, escorte des transits) | Arrêtés DGD (travail supplémentaire) |
| **CCIM** (Carte de Commerce Import-Export) | Formulaire + inscription CCIM | Frais d'impression et d'enregistrement |
| **Droit de timbre** | Immatriculation véhicules (ONT) | 200 à 15 000 FCFA selon papier |
| **Péage Sanankoroba** (corridor Zégoua–Bamako) | Véhicules de transit | Barème péage |
