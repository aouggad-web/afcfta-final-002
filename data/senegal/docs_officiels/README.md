# Sénégal — Taxes, droits et accises collectés par la Douane + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : douanes.sn (DGD), vie-publique.sn, senegal.eregulations.org, USDA FAS.

## 1. Droits et taxes perçus par la Douane à l'importation (TEC CEDEAO + taxation nationale)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **Droit de Douane (DD)** — TEC CEDEAO | Valeur CAF | 0 % / 5 % / 10 % / 20 % / 35 % (5e bande : produits agroalimentaires sensibles) | Exo : produits originaires UEMOA/CEDEAO, TPC UEMOA, SLE CEDEAO |
| **Redevance Statistique (RS)** | Valeur CAF | 1 % | Même les produits exonérés de DD ; exo clauses express partenaires |
| **Prélèvement Communautaire de Solidarité (PCS/PCS-UEMOA)** | Valeur CAF | 0,8 % – 1 % | Ressource affectée à l'Union |
| **Prélèvement Communautaire CEDEAO (PCC)** | Valeur CAF | 0,5 % | Produits pétroliers non soumis (actuellement) |
| **Prélèvement COSEC** (Conseil Sénégalais des Chargeurs) | Valeur CAF, voie maritime uniquement | 0,4 % | Exo : dons à l'État, médicaments, santé publique |
| **PROMAD** (Prélèvement modernisation Administration des Douanes) | Valeur CAF | 2 % | |
| **TVA à l'importation** | VD + DD + RS + taxes intérieures + surtaxes | 18 % | Exo (CGI) : riz, blé, poissons, viandes, fruits/légumes, médicaments, matériel médical, engrais, livres |
| **Droits d'Accises (taxes intérieures / DA)** | VD + DD + RS + surtaxe | 20 % cigarettes éco ; 45 % cigarettes premium et autres tabacs ; 40 % boissons alcoolisées ; 3 % boissons gazeuses ; taux divers (cola 30 %, corps gras 5 %, café/thé 3,8 %…) | |
| **Droit d'enregistrement (véhicules)** | Base + DD + RS | 1 % véhicules neufs ; 3 % véhicules d'occasion ; droit fixe 2 000 FCFA transport public | FAQ 2026 : 1 % neufs / 3 % occasion |
| **Droit d'accises véhicules de tourisme** | Base + DD + RS | 10 % | |
| **Acompte BIC** | Valeur | 3 % | Dispense si attestation DGE (DGID) |
| **Prélèvement de conformité fiscale (PCF)** | Valeur | 12 % | Si pas d'attestation de non-assujettissement DGID |
| **Taxe Conjoncturelle à l'Importation (TCI)** | Prix de déclenchement UEMOA | 10 % (huiles végétales) ; péréquation sucre (PD sucre poudre 325 056 F/t, morceaux 385 059 F/t) | Sucre, huiles, concentré de tomate ; non applicable aux intrants |
| **Taxe dégressive de Protection (TDP)** | — | dégressive | Dispositif complémentaire UEMOA |
| **Surtaxe cigarettes / taxe additionnelle alcools** | — | selon produit | |
| **Taxe spécifique (produits pétroliers)** | Volume | tarif officiel | |
| **Frais d'escorte douanière** | Forfait | arrêté n°07928/MEFP/DGD/DRCI du 30/05/2016 | Opérations commerciales particulières |

## 2. Frais des prestataires / entités étatiques du commerce extérieur

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires en douane agréés (CDA)** | Honoraires (saisie GAINDE/ORBUS, constitution dossier, circuits DGD) | **Librement négociés** (tarifs fixés par la législation des prix — art. 76 Code des douanes) ; débours refacturés au franc près sans marge |
| **CCIAD (Chambre de Commerce de Dakar)** | Carte import-export / CPPM | Frais de dossier 3 500 FCFA ; participation aux charges CCIAD 6 500 FCFA |
| **GAINDE 2000 (GIE)** | Plateforme ORBUS / redevances data | Redevances data Quartz ≈ 10 000 FCFA (+ TVA 18 % = 3 240 FCFA) ; DPI obligatoire ≥ 1 000 000 FCFA FOB (note de service n°00408 DGD/DRCI/SP du 25/01/2022) |
| **Port Autonome de Dakar (PAD)** | Manutention, taxes portuaires | Tarifs officiels PAD ; franchise magasinage 7 jours puis surestaries ≈ 25 000 FCFA/jour/conteneur |
| **Transit CEDEAO (hinterland Mali/Burkina/Mauritanie)** | Caution bancaire obligatoire | Montant = droits et taxes théoriques ; commission bancaire à la charge du client |
| **ANAM** | Droit de trafic maritime (redevance UEMOA, Règlement n°02/2008/CM/UEMOA art. 15) | Facturé via GAINDE 2000 |
| **DGID (Impôts)** | Attestations (PCF, non-assujettissement, DGE) | Obligatoires pour éviter PCF 12 % / acompte BIC 3 % |
