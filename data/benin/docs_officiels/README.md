# Bénin — Taxes, droits et accises collectés par la Douane (DGDDI) + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : douanes.gouv.bj (DGDDI), guce.gouv.bj (GUCE/SEGUB), api.impots.bj (DGI).

## 1. Fiscalité de porte à l'importation (TEC CEDEAO + taxation nationale — loi de finances 2026)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **Droit de Douane (DD)** — TEC CEDEAO | Valeur en douane (CAF) | 0 / 5 / 10 / 20 / 35 % | Tarif officiel DGDDI SH 2022 à jour (2.0) |
| **Redevance Statistique (RS)** | Valeur CAF | 1 % | |
| **Prélèvement Communautaire CEDEAO (PC)** | Valeur CAF | 0,5 % | |
| **Prélèvement Communautaire de Solidarité UEMOA (PCS)** | Valeur CAF | 0,8 % | |
| **TVA à l'importation** | Valeur en douane + droits et taxes | 18 % | CGI Bénin, livre 2 |
| **AIB** — Acompte sur Impôt sur les Bénéfices | VD + droits et taxes (hors TVA) | **1 %** | Liquidé au cordon douanier pour le compte de la DGI ; 3 % pour personnes non connues du fichier DGI |
| **Prélèvement CNF** (non-immatriculés/connaissements rectifiés) | VD + droits et taxes | 10 % | Importateurs inconnus du fichier DGI |
| **Taxe sur les Produits Spécifiques** (droits d'accises) | CAF ou spécifique | barèmes CGI (livre 2, titre 2) | Tabacs, boissons |
| **TSUPP** — Taxe Spécifique Unique sur Produits Pétroliers | Volume | tarif officiel | |
| **Taxe sur les Véhicules de Tourisme** (TVM) | selon catégorie/âge | barème CGI | |
| **Prélèvement forfaitaire véhicules d'occasion** | Forfait | barème CGI | |
| **Taxe sur l'exportation de la ferraille** | Tonne | **50 000 FCFA/t** | Recouvrée par la DGDDI pour la DGI |

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Commissionnaires Agréés en Douane (CDA)** | Obligatoires (décret 99-653 du 22/11/1999) ; cotation, ordre de transit, déclaration SYDONIA World | Honoraires libres |
| **GUCE / SEGUB** (Guichet Unique du Commerce Extérieur, opérationnel 15/03/2018) | DVT, Intention d'Importation électronique (e-IDI), demande AVD, BFU, paiement électronique, tarif en ligne, simulation droits/taxes | Prestations GUCE selon barème ; BFU = **Bordereau de Frais Unique** regroupant toutes les factures (douane + manutentionnaire + PAC + CCIB + CNERTP + SEGUB…) payées en une fois à la banque |
| **Bénin Control** | Vérification documentaire et de valeur → **AVD** (Attestation de Vérification Documentaire = valeur transactionnelle de référence) | Contestation via comité d'arbitrage (arrêté ministériel) |
| **GUOCE → GUCE** (pré-dédouanement) | Bordereau Unique de Pré-dédouanement (BUP) : récapitulatif frais des structures émettrices (permis, certificats) | Payable banques partenaires (arrêté n°97 : barème certificats/permis) |
| **Guichet Unique Portuaire (GUP)** | Annonce escale, manifeste, appelé camion, BFU | Arrêté exploitation GU port Cotonou |
| **Manutentionnaire / Port Autonome de Cotonou (PAC)** | Acconage (manutention), magasinage | Facture d'acconage ; franchise/surestaries selon tarif PAC |
| **Consignataires / agents maritimes** | Bon à délivrer | Facture |
| **CNCB / CNERTP / CCIB / SEGUB** | Structures émettrices facturées sur le BFU | Barèmes propres (CCIB : certificats d'origine) |
| **Cautions transit** | Acquits-à-caution transit ordinaire/international ; **véhicules d'occasion en transit : suivi électronique (tracking) obligatoire** + Attestation de Suivi Électronique (ASE) | Redevances de transit aux recettes frontières |
| **SYDONIA World** | Saisie déclaration DDU, sélectivité (circuits vert/jaune/rouge), liquidation | Via GUCE/CDA |
