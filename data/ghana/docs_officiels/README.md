# Ghana — Taxes, droits et accises collectés par la Douane (GRA) + frais des prestataires du commerce extérieur

Dossier de livrables (collecte du 10/10/2026). Sources : gra.gov.gh, shippers.org.gh, ghanaports.gov.gh, mofep.gov.gh, trade.gov.

## 1. Droits et taxes perçus par la Douane (GRA Customs, via ICUMS)

| Taxe | Base | Taux | Remarques |
|---|---|---|---|
| **Import Duty (CET CEDEAO)** | CIF | 0 % / 5 % / 10 % / 20 % / 35 % | 5 bandes TEC (Customs Act 2015, Act 891 + Amendment Act 915) |
| **Import VAT** | CIF + Duty + NHIL + GETFund | 15 % (unifié, VAT Act 2025 / Act 1151, en vigueur 01/01/2026) | Flat rates 3 %/5 % supprimés ; Covid-19 levy aboli |
| **NHIL** (National Health Insurance Levy) | CIF (cascade aux ports) | 2,5 % | Déductible en input VAT depuis 2026 (sauf imports) |
| **GETFund Levy** | CIF | 2,5 % | Idem |
| **AU Import Levy** | CIF (hors États UA) | 0,2 % | |
| **ECOWAS Levy** | CIF (hors CEDEAO) | 0,5 % | |
| **EXIM Levy** | CIF (hors pétrole) | 0,75 % | Ghana EXIM Bank (Act 911) |
| **Special Import Levy (SIL)** | CIF (hors pétrole, engrais, machines) | 2 % | Act 861 amendé |
| **Import Excise Duty** | selon produit (5e Schedule) | tarif CET | Alcools, tabacs… |
| **Examination Fee** | CIF | 1 % | Véhicules d'occasion uniquement |
| **Processing Fee** | — | selon cas | Ex-warehouse, duty-free, véhicules |
| **Overage Penalty** (véhicules âgés) | CIF | selon âge/type | Ambulances/corbillards/8705 exonérés |
| **Upfront payment** (importateurs non enregistrés VAT) | Valeur en douane | **20 %** si valeur > GHS 750 000 | Récupérable après enregistrement VAT (rais. 12,5 % → 20 % en 2026) |
| **Export duties** | 4e Schedule du Tariff | selon produit | Produits nationaux (cacao/café/karité exclus des exports non traditionnels taxés) |

**Nouveautés 2026 (VAT Act 2025, Act 1151)** : TVA unifiée 15 %, NHIL+GETFund sur la même base (anti-cascade intérieure), abonnement services : seuil GHS 750 000 (biens), seuil supprimé pour services ; pénalités de non-enregistrement portées à 3× la taxe.

## 2. Frais mandataires / prestataires / entités étatiques

| Prestataire / entité | Prestation | Tarif / règle |
|---|---|---|
| **Clearing Agents** (obligatoires par loi) | Honoraires de dédouanement | **Tarifs maximaux négociés par la Ghana Shippers' Authority** (L.I. 2190) : conteneur 20' GHS 907,20 · 40' GHS 1 209,60 · vrac ≤5 t GHS 362,88 (+45,36/t) · camion articulé GHS 945 · voiture import GHS 756 ; services spéciaux : warehousing 264,60 · CCVR processing 189/BL · dangerous goods 567/TEU… |
| **GPHA** (Ghana Ports & Harbours Authority) | Port dues cargo | Conteneurs import : 70,07 $ (20') / 132,50 $ (40') · vrac sec 2,66–4,66 $/t · conventionnel 5,32 $/t · port dues navires 0,18 $/GT · PIDD, ISPS… (Port Tariffs août 2023) |
| **GPHA** | Permis d'exploitation 2026 (freight forwarders, self-declarants, NVOCC…) | Freight forwarder clearing/forwarding : renewal GHS 795 / nouveau GHS 3 480 · consolidators 3 480/6 960 · self-declarant importateur 1 100/3 480 · scanning cos 7 610/13 340 ; amendes tarifaires (3× le montant indû) |
| **FDA** (Food & Drugs Authority) | Permis importateur + enregistrement produit | Importer fee : 0,8 % aliments · 1,8 % médicaments · 0,5 % cosmétiques (via ICUMS, permis 1 an) |
| **GSA** (Ghana Standards Authority) | Conformité, tests | Enregistrement produits GHS 100 (3 premiers) puis 50 ; 1 % CIF pour marchandises à haut risque |
| **Ghana Chamber of Commerce** | Certificats d'origine | Facturés en USD par consignement |
| **Ghana Shippers' Authority** | Shippers Council levy | Sur tous les imports (négociation des tarifs pour les chargeurs) |
| **Terminal operators** (Tema/Takoradi) | THD, magasinage, surestaries | Tarifs GPHA négociés (Shippers Authority) : franchise 7 j puis rent (p.ex. conteneur plein 13,46 GHS/j → 39,78) |
| **MOTI / GEPA** | Import Declaration Form GHS 5 ; registration GEPA GHS 200/an | |
| **Transit** | Caution + transit rates (GHS/CFA) | Ex. voiture 378 000 CFA… |
